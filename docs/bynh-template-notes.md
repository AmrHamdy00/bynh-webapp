# Bynh — Webflow template notes (Radiant Templates)

Reviewed: 50 templates (batch 1: 22, batch 2: 28).

Purpose: short notes on every template reviewed, so we can mix the best ideas into the new bynh.sa.
Checked against our rules: Bynh navy palette only, white ground, IBM Plex Sans Arabic, RTL, no phone mockups /
app screenshots, no navy cards, no giant numerals on cards, no dark theme, original copy only.

Verdict key: ★ keep as reference · ◐ borrow one idea · ✕ skip

### New ideas from batch 2
- Lexa: page model — knowledge base + help center + case studies as CMS → «الأسئلة الشائعة», guides for clients, maybe lawyer success stories.
- Saasoft / Softrix: numbered list rows with arrow (feature rows) — fits our hairline `.rows` style for services.
- Advantek / Saasoft / Apland: huge faint "ghost" word behind a section title — could be «بيّنه» or the section name in tint #E9F0F4.
- Saasyfy / Lexa: dedicated help-center page.

## Ideas worth mixing into bynh.sa (batch 1)
- Ostack: scroll-driven word reveals on long paragraphs; one pinned "problem → solution" band (fits «تحتاج استشارة أو خدمة قانونية؟» → services).
- Ostack / Teknify / BotCloud: a knowledge-base / help-center page → could host «الأسئلة الشائعة» + blog categories.
- Arodesk / Ostack: dedicated team-member page → lawyer profile page pattern.
- Operio: quieter headline typography with one accent word (we already do this with `.soft`).
- Neurixo / Soltio: giant scrolling marquee word — only if done in navy on white, e.g. «بيّنه».
